Это проекта микро ORM на подобии Dapper. но для разных провайдеров база данных таких как: SQL server, SQlite
Основаня идея:
1. Построение выражений при помощи методов-расширения, на подобии DSL
2. Интерпритация выражений в SQL запросы
3. Маппинг результатов запроса в типизированые объекты
4. Возможно легко расширять ORM, для других БД
Структура проекта
1. QMap - предствляет из себя интерфейс взаимодействия с IDbConnection. Содержит конечные реализации для запросов.
2. QMap.Core - содержит в себе общие абстракции над IDbConnection, для создания единого интерфейса взаимодействия 
3. QMap.Mapping - отвечает за маппинг "сырых" строк из БД в типизированные коллекции 
4. QMap.SqlBuilder - содержит абстракции для каждой ноды SQL синтаксиса которая нуждается в интепритации выражения/параметрезации. Интепретирует вырважения Expressions в SQL код
5. QMap.SqlLite - библиотека-адаптер для работы с SQLite. Содержит конкретную реализацию интерфейсов из QMap.Core для специфики работы с SQLite
Правила работы с проектом.
1. Переиспользовать существующий код API
2. Использование встроенных абстракций и следование общему интерфейсу
3. После добавления нового функционала в QMap.SqlBuilder  или QMap нужно написать тесты
4. Нельзя удалять что-то из существующей арихитектуры, только расширять
